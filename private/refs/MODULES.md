# Getting Started: The Modules

We update quite regularly those modules.

## Before Comitting:

Run ./tools/updater.py instead! You might be missing updated modules first.

## Abstract:

- `krnl`: The Ne.app Kernel System Module.
- `ncc`: The NCC Toolchain/PL Module.
- `boot`: The NextBoot BCSA Firmware Module.
- `nebuild`: The NeBuild Build System Module.
